# Mi Sitio

Proyecto de arranque para trabajar con Claude Code desde el iPad.

## Cómo usarlo

1. Sube estos archivos a un repositorio nuevo en GitHub (arrastra la carpeta en "Add file → Upload files").
2. Abre la app de Claude en tu iPad, ve a la pestaña **Code**, conecta tu cuenta de GitHub y selecciona este repositorio.
3. Descríbele a Claude Code qué quieres cambiar o agregar al sitio.

## Proyecto de video (Remotion)

La carpeta `video/` contiene un proyecto de [Remotion](https://www.remotion.dev/) generado con `npx create-video@latest`, listo para crear videos programáticamente con React.

```console
cd video
npm i
npm run dev
```
